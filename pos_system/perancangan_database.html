Perancangan Database

Sistem Point of Sales (POS) – Toko Fenny Grosir

Nama Database : pos_fenny  ·  DBMS : MySQL 8.x  ·  Charset : utf8mb4_unicode_ci

Relasi Antar Tabel (Entity Relationship)

  • users — 1 : N —▶ transaksi  (users.id = transaksi.id_user)
  • kategori — 1 : N —▶ produk  (kategori.id = produk.id_kategori)
  • transaksi — 1 : N —▶ detail_transaksi  (transaksi.id = detail_transaksi.id_transaksi)
  • produk — 1 : N —▶ detail_transaksi  (produk.id = detail_transaksi.id_produk)

Tabel 1  :   users

Menyimpan data akun pengguna sistem (Admin dan Kasir).

No. Nama Field Tipe Data Ukuran Default Key / Constraint Keterangan
1 id INT 11 — PK AUTO_INCREMENT Identitas unik pengguna
2 nama VARCHAR 100 NOT NULL — Nama lengkap pengguna
3 username VARCHAR 50 NOT NULL UNIQUE Nama pengguna untuk login
4 password VARCHAR 255 NOT NULL — Kata sandi terenkripsi (bcrypt)
5 role ENUM — 'kasir' — Hak akses: 'admin' / 'kasir'
6 foto VARCHAR 255 NULL — Nama file foto profil (opsional)
7 created_at TIMESTAMP — CURRENT_TIMESTAMP — Waktu akun dibuat

Tabel 2  :   kategori

Menyimpan data kategori / kelompok produk.

No. Nama Field Tipe Data Ukuran Default Key / Constraint Keterangan
1 id INT 11 — PK AUTO_INCREMENT Identitas unik kategori
2 nama_kategori VARCHAR 100 NOT NULL — Nama kategori produk
3 created_at TIMESTAMP — CURRENT_TIMESTAMP — Waktu kategori ditambahkan

Tabel 3  :   produk

Menyimpan data barang yang dijual di toko.

No. Nama Field Tipe Data Ukuran Default Key / Constraint Keterangan
1 id INT 11 — PK AUTO_INCREMENT Identitas unik produk
2 kode_produk VARCHAR 20 NOT NULL UNIQUE Kode unik / SKU produk
3 nama_produk VARCHAR 150 NOT NULL — Nama lengkap produk
4 id_kategori INT 11 NOT NULL FK → kategori.id Referensi ke tabel kategori
5 harga_beli DECIMAL 15, 2 NOT NULL — Harga beli / modal produk
6 harga_jual DECIMAL 15, 2 NOT NULL — Harga jual kepada pelanggan
7 stok INT 11 0 — Jumlah stok tersedia di gudang
8 gambar VARCHAR 255 NULL — Nama file foto produk (opsional)
9 created_at TIMESTAMP — CURRENT_TIMESTAMP — Waktu produk ditambahkan

Tabel 4  :   transaksi

Menyimpan header / kepala setiap transaksi penjualan yang dilakukan kasir.

No. Nama Field Tipe Data Ukuran Default Key / Constraint Keterangan
1 id INT 11 — PK AUTO_INCREMENT Identitas unik transaksi
2 kode_transaksi VARCHAR 20 NOT NULL UNIQUE Nomor nota / kode transaksi
3 id_user INT 11 NOT NULL FK → users.id Kasir yang memproses transaksi
4 total_harga DECIMAL 15, 2 NOT NULL — Total nilai seluruh item transaksi
5 uang_bayar DECIMAL 15, 2 NOT NULL — Uang yang diberikan pelanggan
6 kembalian DECIMAL 15, 2 NOT NULL — Kembalian = uang_bayar − total_harga
7 tanggal DATETIME — NOT NULL — Tanggal dan waktu transaksi
8 created_at TIMESTAMP — CURRENT_TIMESTAMP — Waktu record dibuat

Tabel 5  :   detail_transaksi

Menyimpan detail item (produk) yang dibeli pada setiap transaksi.

No. Nama Field Tipe Data Ukuran Default Key / Constraint Keterangan
1 id INT 11 — PK AUTO_INCREMENT Identitas unik baris detail
2 id_transaksi INT 11 NOT NULL FK → transaksi.id Referensi ke header transaksi
3 id_produk INT 11 NOT NULL FK → produk.id Referensi ke tabel produk
4 jumlah INT 11 NOT NULL — Banyak item produk yang dibeli
5 harga_satuan DECIMAL 15, 2 NOT NULL — Harga jual saat transaksi berlangsung
6 subtotal DECIMAL 15, 2 NOT NULL — jumlah × harga_satuan

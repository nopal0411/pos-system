UC-01 Login Sistem
AdminKasir
 Admin dan Kasir melakukan autentikasi dengan memasukkan username dan password untuk mengakses sistem POS.
UC-02 Manajemen Barang
Admin
 Admin mengelola data barang meliputi tambah, ubah, hapus produk, serta memantau dan memperbarui stok barang di toko.
UC-03 Laporan Penjualan
Admin
 Admin mengakses laporan rekap penjualan harian/bulanan untuk evaluasi performa toko dan pengambilan keputusan bisnis.
UC-04 Proses Transaksi Penjualan
Kasir
 Kasir memproses penjualan: memilih produk, memasukkan jumlah, menghitung total harga, menerima pembayaran, dan mengembalikan kembalian. «include» pencarian produk.
UC-05 Pencarian Produk (Linear Search)
Kasir
 Sistem mencari produk berdasarkan nama/kode menggunakan Algoritma Linear Search secara sekuensial. Merupakan bagian wajib (include) dari proses transaksi.
UC-06 Cetak Struk / Invoice
Kasir
 Setelah transaksi selesai, Kasir mencetak struk berisi rincian produk, total harga, jumlah bayar, dan kembalian sebagai bukti transaksi.
UC-07 Logout
AdminKasir
 Admin dan Kasir mengakhiri sesi kerja dengan keluar dari sistem untuk menjaga keamanan data dan akses sistem POS.
